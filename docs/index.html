Rao X

Среда дискретно-событийного моделирования. Проверенная конфигурация: Windows x64, Java 21, Eclipse 2025-09, Xtext 2.40.0. Документация открывается прямо с диска; сервер и доступ к сети для чтения справки не требуются.

Начните с Windows quick start: сборка, установка, первая модель и проверка результата. Для разработчика — архитектура, генерация, отладка, форматы, тесты и выпуск (Markdown, откройте в редакторе или на GitHub), команды сборки и состояние восстановления.
