Первая модель на Windows

Документация Rao X · Повторно проверено 22 октября 2026 года.

1. Инструменты и исходники

Нужны Windows 10 1903+ или Windows 11 x64, Git и PowerShell 7 (pwsh). Сеть нужна для первой загрузки инструментов и зависимостей. Java, Maven и Eclipse загрузит скрипт; системный PATH он не меняет. Для компиляции достаточно PowerShell 5.1, но упаковка требует PowerShell 7.

Разместите исходники в ASCII-пути, например C:\work\raox. Пробелы разрешены; кириллица в пути исходников пока не поддержана генератором. Команды выполняйте из корня репозитория в PowerShell 7.

Получите основную ветку release/current из fork или распакуйте переданный архив исходников в C:\work\raox.

git clone https://github.com/Propinbo/raox.git C:\work\raox
Set-Location C:\work\raox
.\recovery\Initialize-Platform.ps1 -IncludeUi
.\recovery\Invoke-PlatformBuild.ps1 -Clean

При использовании архива пропустите git clone. В корне должны лежать pom.xml, mvnw.cmd и папка recovery. Точка передачи и результаты проверок записаны в STATE.md.

Ожидается BUILD SUCCESS, 38 JUnit без ошибок и пропусков, затем успешная сверка пакета и зависимостей. Инструменты лежат в .build/platform-tools, кэш — в .build/platform-m2, полный лог и JSON — в .build/platform-evidence.

2. Собрать и установить приложение

.\recovery\New-WindowsDistribution.ps1
Expand-Archive -LiteralPath .\assembly\target\windows-x64\raox-3.9.0-windows-x86_64.zip -DestinationPath C:\work\raox-app
& C:\work\raox-app\raox\eclipse.exe -data C:\work\raox-workspace

Выберите ещё не существующие каталоги распаковки и workspace. Если получили готовый ZIP, начните с распаковки: в нём уже есть Java 21 и плагины. Архив распаковывается целиком в доступный для записи каталог. Установленный продукт и workspace допускают пробелы и кириллицу. На повторной упаковке задайте новый -OutputRoot .build/distribution-next.

3. Создать модель

  1. Закройте Welcome, если он открыт. При необходимости выберите Window → Perspective → Open Perspective → Other… → Rao → Open.
  2. Откройте File → New → Project…, в фильтре Wizards введите rao, выберите Rao X → Rao X Project → Next.
  3. Project name: hello, Templates: Пустая модель, нажмите Finish.
  4. В hello.rao замените весь текст следующим кодом и сохраните Ctrl+S.
type Counter { int n }
resource counter = Counter.create(0)

event Tick() {
    counter.n = counter.n + 1
    Tick.plan(currentTime + 1)
}

def init() { Tick.plan(0) }
def terminateCondition() { return currentTime >= 3 }
result total = Result.create([counter.n], new LastValueStatistics())

4. Запустить и сверить результат

  1. Дождитесь окончания фоновой сборки; в Problems не должно быть ошибок. В Monitoring Configuration отметьте корневой узел hello.
  2. Оставьте редактор hello.rao активным и нажмите кнопку с подсказкой Execute model hello.
  3. В Results найдите hello.hello.total: Last value: 4. В Trace последняя строка — ES 3.0 Simulation finished: terminate condition.
  4. Выберите Model → Export Results и Model → Export Trace Output → Regular. В проекте появятся hello.res и hello.trc.

События Tick выполняются в моменты 0, 1, 2 и 3. Условие завершения проверяется после исполнения очередного шага, поэтому счётчик равен четырём. В hello.res ожидается:

hello.hello.total
  Last value: 4

Фрагмент hello.trc:

EI 0.0 Tick[0]
...
EI 3.0 Tick[3]
...
ES 3.0 Simulation finished: terminate condition

В Collected Objects выберите hello → Results → total. Сначала откройте график через контекстное меню Plot и оставьте его открытым. Затем снова выберите total в Collected Objects: Export to CSV / Export to JSON сохраняет точки. Эти команды доступны, пока график открыт. С включённым мониторингом точки равны (0,0), (0,1), (1,2), (2,3), (3,4): первая точка соответствует состоянию до первого события.

Если результат отличается

  • Нет меню Rao X: проверьте, что запущен распакованный продукт из шага 2.
  • Нет событий в Trace: отметьте hello в Monitoring Configuration до запуска и повторите его.
  • Нет кнопки Execute: откройте перспективу Rao и активируйте редактор hello.rao.
  • Ошибки типов или classpath: убедитесь, что проект создан мастером Rao X, а не Java Project; не переносите старые .classpath с абсолютным путём к runtime JAR.
  • Сборка завершилась ошибкой: сохраните первый сбой из *-verify.log и *-verify.json; команды диагностики — в инструкции сборки.

Далее: подсчёт звонков, очередь и оператор, устройство и отладка проекта.
