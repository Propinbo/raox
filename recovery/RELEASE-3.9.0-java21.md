SHA-256 Windows ZIP:
`33b90973b7fa6c687303f6457463a5688c837ca45a96f92beb97205b6a09565c`.

Проверить скачанный файл:

```powershell
Get-FileHash -Algorithm SHA256 .\raox-3.9.0-windows-x86_64.zip
```

Распакуйте весь ZIP и запустите `raox/eclipse.exe`, выбрав новый workspace.
Отдельные Java и Eclipse не нужны. Требуется Windows 10 1903+ / Windows 11 x64.
Сборку исходников выполняйте в ASCII-пути; Linux на новой платформе не проверен.

## Проверки перед публикацией

Публикация выполняется после проверки скачанного из CI ZIP: 1 362 файла по manifest,
native launcher без системной Java в Unicode-пути, SWT/AWT, 811 классов относительно
контрольного продукта, весь RCPTT-набор и CSV/JSON. Ожидаются 38 JUnit в CI,
43 RCPTT одним прогоном, без ошибок и пропусков. Фактические результаты входят
в `release-manifest.json` и архив свидетельств; начавшийся прогон не считается успешным.
